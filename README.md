# Takshashila Critical Minerals page

A Quarto implementation of a Takshashila Institution critical minerals programme page, modelled on the structure and visual language of the existing Space Power page.

## Preview locally

Install [Quarto](https://quarto.org/docs/get-started/) and run:

```bash
quarto preview
```

For a production render:

```bash
quarto render
```

The generated site is written to `_site/`.

## What is included

- The programme approach
- Takshashila research on critical minerals and rare earths
- Relevant analysis and op-eds
- Five policy positions, preserved verbatim from the supplied source
- Pranay Kotasthane, Shobhankita Reddy, and Tannmay Kumarr Baid
- The Politics and Policy of Critical Minerals Expert Capsule Course
- GitHub Actions deployment to GitHub Pages
